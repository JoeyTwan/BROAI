# BRO AI - 智能需求澄清助手需求文档

## 1. 项目背景

BRO AI 是一款基于通义千问（Qwen）的AI聊天助手，通过多轮对话澄清用户需求并生成高质量内容。它旨在帮助用户更清晰地表达需求，并通过AI的智能分析生成符合要求的内容。

### 1.1 项目定位

- **产品类型**：AI驱动的智能需求澄清助手
- **目标用户**：不会写精准的提示词 或 懒得写很多提示词，但有精准内容需求的用户
- **核心价值**：通过多轮对话帮助用户澄清需求，生成高质量内容

### 1.2 问题陈述

- 用户在生成内容时，常常先入为主，无法清晰表达自己的需求
- 传统AI助手一次性生成内容，缺乏需求澄清过程，体验感不好，提示词学习成本大
- 不同用户对内容的背景、目标受众、等要求各不相同

### 1.3 解决方案

BRO AI 通过以下方式解决上述问题：

- 采用多轮对话方式，逐步澄清用户需求
- 每次只问一个问题，确保信息收集的准确性
- 按照固定顺序确认需求的各个方面
- 只有在信息充分时才生成最终内容

## 2. 功能模块

### 2.1 用户认证系统

- **注册功能**：允许用户创建新账号
- **登录功能**：支持已注册用户登录
- **身份验证**：使用JWT令牌进行身份验证
- **用户信息管理**：允许用户查看和管理个人信息

### 2.2 AI聊天功能

- **智能需求澄清**：通过多轮对话了解真实需求
- **流式输出**：打字机效果展示AI回复
- **Markdown支持**：支持基本的Markdown格式
- **消息复制**：允许用户复制AI回复

### 2.3 会话管理

- **新建会话**：支持创建新的对话会话
- **会话列表**：显示所有会话
- **会话重命名**：允许用户修改会话名称
- **会话置顶**：支持将重要会话置顶
- **会话删除**：允许用户删除会话
- **会话同步**：登录后自动同步会话到服务器

### 2.4 反馈系统

- **反馈提交**：允许用户提交反馈意见
- **反馈点赞**：支持用户为反馈点赞
- **反馈管理**：管理员可以管理用户反馈

### 2.5 用量统计

- **每日限制**：设置每日免费调用次数（默认100次）
- **用量显示**：实时显示今日已用次数和剩余次数
- **自动重置**：每日00:00自动重置用量
- **用量查询**：提供API查询当前用量

## 4. 业务流程

### 4.1 认证流程

1. 用户访问BRO AI应用
2. 用户点击"登录/注册"按钮
3. 用户选择"注册"或"登录"
4. 用户输入邮箱和密码
5. 系统验证用户信息
6. 验证成功后，用户登录到系统
7. 系统返回JWT令牌，用于后续API调用

### 4.2 聊天流程

1. 用户登录到BRO AI
2. 用户输入初始需求
3. 系统检查用户每日用量
4. 用量充足时，系统将需求发送给AI模型
5. AI模型生成澄清问题
6. 系统将AI回复返回给用户
7. 用户回答AI问题
8. 重复步骤3-7，直到需求明确
9. AI生成最终内容
10. 系统将最终内容返回给用户

### 4.3 会话管理流程

1. 用户登录到BRO AI
2. 用户查看会话列表
3. 用户选择以下操作之一：
   - 新建会话
   - 重命名会话
   - 置顶会话
   - 删除会话
4. 系统执行相应操作
5. 系统更新会话列表
6. 系统将更新后的会话同步到服务器

## 5. 非功能性需求

### 5.1 性能

- **响应时间**：AI回复应在5秒内开始流式输出
- **并发处理**：支持至少100个并发用户
- **系统可用性**：系统可用性达到99.9%

### 5.2 安全

- **数据加密**：用户密码使用bcrypt加密存储
- **API认证**：所有API调用使用JWT令牌认证
- **CORS保护**：严格配置CORS策略，只允许信任的域名访问
- **环境变量管理**：敏感配置信息通过环境变量管理，不硬编码到代码中

### 5.3 可用性

- **界面友好**：简洁直观的用户界面，易于使用
- **错误处理**：友好的错误提示，帮助用户理解和解决问题
- **文档完善**：提供详细的用户指南和API文档

### 5.4 可扩展性

- **模块化设计**：系统采用模块化设计，便于添加新功能
- **API设计**：提供RESTful API，便于与其他系统集成
- **数据库设计**：灵活的数据库设计，支持未来扩展

### 5.5 可靠性

- **数据备份**：定期备份用户数据
- **错误恢复**：系统出现错误时，能够快速恢复
- **日志记录**：详细记录系统操作和错误，便于调试和分析

## 6. 技术栈

- **前端**：React 18 + Vite + Tailwind CSS
- **后端**：Node.js 18 + Express + PostgreSQL (Supabase)
- **认证**：JWT + bcrypt
- **AI**：通义千问 Dashscope 兼容接口
- **部署**：Vercel (前端) + Railway/Render (后端)
